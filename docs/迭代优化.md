针对的场景：
PDF矢量型（非位图型）的对账单文件，提取出表格excel

总的思路是：
寻找表格区域，裁剪表格，提取表格，数据清洗，输出表格

工具上：
使用pdfplumber，cpu部署

总pipeline上，负责做批量处理的单文件逻辑：
find_tables ->
crop_tables ->
extract_excel ->
clean_excel ->
output_excel

策略分发pipelines上，负责做单页PDF处理的单页逻辑：
需要对基类进行方法重写，针对常规和特殊银行做策略分发，常规的使用通用的设置，特殊的格式使用专门的优化。

装饰器：
用于时间记录、日志打印、异常处理。

总main调用上，负责做批量处理的总流程逻辑。

重难点：
find_tables 
使用settings策略对表格进行定位，并返回表格的左上右下的坐标值，即bbox。

crop_tables
先进行校验ROI，然后再进行裁剪。
准确找表格的左上右下的坐标值，做了类似于上下边界的游标。
表头游标根据“摘要”来定位，并且向上留有一定容错空间，约为9个像素点。
表尾游标根据综合逻辑，比如“第x页/共x页”等正则、来寻找表尾位置.

extract_excel
获取裁剪后的图片，并使用settings策略进行表格提取。

clean_data
对生成的表格进行数据清洗整理，如：
pdf矢量去除水印、断行合并、列合并拆分、去除重影字符、针对特殊银行的处理工具
